# Factuality Test Bot

[Factuality Test Bot](https://t.me/factuality_test_bot) - это интерактивный Telegram-бот, основанный на книге "Фактологичность" Ханса Рослинга, профессора международного здравоохранения и известного спикера TED.


## Что делает бот
- Проводит тест из 13 вопросов
- Показывает правильные ответы с объяснениями
- Помогает увидеть распространённые заблуждения о мире
- Поддерживает английский, русский, испанский и украинский языки



## Основные команды
```
/information  - Узнать больше о боте
/language     - Выбрать язык бота
```


## Локализация

В первом ряду выбора языка расположены английский и русский, во втором —
испанский и украинский. Выбранный язык сохраняется без сброса ответов теста.
Сообщения бота и описания команд локализованы; описание профиля и картинка
настраиваются отдельно через BotFather.

После изменения каталога переводов его нужно скомпилировать:
```
pybabel compile -d locales -D bot_06_factuality
```

Изолированные проверки локализации при установленных зависимостях проекта:
```
python -m unittest discover -s testing -p test_localization.py -v
```

## Технологии
- 🐍 Python + Aiogram 3.x

- 🔄 Redis для управления состояниями

## О книге «Фактологичность»

«Фактологичность» – это книга, итог многолетних исследований Ханса Рослинга, профессора международного здравоохранения. Автор проводил тесты среди студентов, политиков, ученых и даже нобелевских лауреатов по всему миру.

Большинство участников, независимо от образования или профессиональной подготовки, справлялись хуже, чем если бы выбирали ответы случайным образом. Рослинг иллюстрирует это примером обезьяны, которой предлагалось выбрать один из трех бананов: используя такой подход, она угадывала 4 из 13 правильных ответов, тогда как люди набирали всего 2-3 правильных ответа из 13. Это показало, что даже эксперты подвержены когнитивным искажениям и стереотипам.

Ханс Рослинг рассказывает про когнитивные искажения и основные инстинкты, заставляющие нас драматизировать и искажать реальность, и предлагает советы для более рационального мышления.

Тест основан на данных, собранных автором для книги. Каждый вопрос в тесте выявляет распространённые заблуждения о глобальных тенденциях, таких как уровень бедности, доступ к образованию и здравоохранению.


## Актуальность данных (UPD 2025)

Книга и тест созданы в 2015 году.
За 10 лет некоторые данные изменились:
- Население Земли: 7 млрд → 8,2 млрд
- Доступ к электричеству: ~80% → ~90%
- Крайняя нищета: сократилась почти втрое (28% → 9%)

Однако суть теста остаётся актуальной - он проверяет когнитивные искажения и инстинкты, а не точные цифры. Все тренды сохранились.

После прохождения теста бот показывает для каждого вопроса: правильный ответ, объяснение, UPD данные 2025 года.
